# Шпаргалка по высшей математике: Интегральное исчисление

## 1. Неопределенный интеграл, понятие, свойства. Таблица интегралов.

**Определение:**
Операция, обратная дифференцированию. Функция $$F(x)$$ называется **первообразной** для функции $$f(x)$$ на промежутке $$X$$, если для всех $$x \in X$$ выполняется $$F'(x) = f(x)$$.

**Неопределенный интеграл** — это совокупность всех первообразных функции $$f(x)$$:

$$\int f(x) dx = F(x) + C$$

где $$C$$ — произвольная константа (так как производная константы равна нулю).

**Свойства (линейность):**

1. Производная от интеграла равна подынтегральной функции: $$\left( \int f(x) dx \right)' = f(x)$$.
2. Интеграл от дифференциала функции равен самой функции плюс константа: $$\int dF(x) = F(x) + C$$.
3. **Постоянный множитель** выносится за знак интеграла: $$\int k \cdot f(x) dx = k \int f(x) dx$$.
4. **Интеграл суммы/разности** равен сумме/разности интегралов: $$\int (f \pm g) dx = \int f dx \pm \int g dx$$.

**Таблица основных интегралов (базовый набор):**

| Функция | Интеграл |
| :--- | :--- |
| $$0$$ | $$\int 0 dx = C$$ |
| $$x^n$$ $$(n \neq -1)$$ | $$\int x^n dx = \frac{x^{n+1}}{n+1} + C$$ |
| $$\frac{1}{x}$$ | $$\int \frac{dx}{x} = \ln|x| + C$$ |
| $$a^x$$ | $$\int a^x dx = \frac{a^x}{\ln a} + C$$ |
| $$e^x$$ | $$\int e^x dx = e^x + C$$ |
| $$\sin x$$ | $$\int \sin x dx = -\cos x + C$$ |
| $$\cos x$$ | $$\int \cos x dx = \sin x + C$$ |
| $$\frac{1}{\cos^2 x}$$ | $$\int \frac{dx}{\cos^2 x} = \tan x + C$$ |
| $$\frac{1}{\sin^2 x}$$ | $$\int \frac{dx}{\sin^2 x} = -\cot x + C$$ |
| $$\frac{1}{\sqrt{1-x^2}}$$ | $$\int \frac{dx}{\sqrt{1-x^2}} = \arcsin x + C = -\arccos x + C$$ |
| $$\frac{1}{1+x^2}$$ | $$\int \frac{dx}{1+x^2} = \arctan x + C = -\arccot x + C$$ |

## 2. Основные методы интегрирования.

**А) Непосредственное интегрирование.**

Использование свойств линейности и табличных интегралов для преобразования подынтегрального выражения (например, раскрытие скобок, деление многочлена на одночлен) без введения новых переменных.

**Б) Метод подстановки (замена переменной).**

Основан на инвариантности формы интеграла. Вводим новую переменную $$t = \varphi(x)$$ или $$x = \psi(t)$$, находим дифференциал $$dx = \psi'(t) dt$$. Цель — свести интеграл к табличному.

*Формула:*

$$\int f(x) dx = \int f(\varphi(t)) \cdot \varphi'(t) dt$$

*Пример:* $$\int \sin(2x) dx = \frac{1}{2} \int \sin(2x) d(2x) = -\frac{1}{2}\cos(2x) + C$$.

**В) Интегрирование по частям.**

Применяется, когда подынтегральная функция является произведением двух разнородных функций. Используется формула, следующая из правила дифференцирования произведения:

$$\int u dv = u v - \int v du$$

*Правило выбора:* За $$u$$ принимаем функцию, которая упрощается при дифференцировании (логарифмы, аркфункции, многочлены). За $$dv$$ — оставшуюся часть, которая легко интегрируется ($$e^x$$, $$\sin x$$, $$\cos x$$).

## 3. Интегрирование функций, содержащих квадратный трехчлен в знаменателе.

Интегралы вида $$\int \frac{Ax + B}{ax^2 + bx + c} dx$$. Метод основан на выделении полного квадрата в знаменателе.

**Алгоритм:**

1. Выделяем полный квадрат:

$$ax^2 + bx + c = a\left[\left(x + \frac{b}{2a}\right)^2 + \left(\frac{c}{a} - \frac{b^2}{4a^2}\right)\right]$$

2. Вводим замену $$t = x + \frac{b}{2a}$$, тогда знаменатель приводится к виду $$t^2 \pm k^2$$.
3. Числитель $$Ax + B$$ выражаем через $$t$$: он распадается на два слагаемых.
   - Первое дает интеграл вида $$\int \frac{dt}{t^2 \pm k^2}$$ (арктангенс или логарифм).
   - Второе дает интеграл вида $$\int \frac{2t \, dt}{t^2 \pm k^2}$$, который берется заменой $$z = t^2 \pm k^2$$ и дает логарифм знаменателя.

**Итог:** Ответ всегда выражается через логарифм и арктангенс.

## 4. Интегрирование рациональных функций.

Рациональная функция — это отношение двух многочленов $$R(x) = \frac{P(x)}{Q(x)}$$. **Метод:** разложение на простейшие дроби.

**Алгоритм:**

1. **Проверка правильности:** Если степень $$P \ge$$ степень $$Q$$, делим многочлен "уголком" до получения правильной дроби (целая часть + остаток).
2. **Разложение знаменателя:** $$Q(x)$$ раскладываем на линейные и квадратичные множители (неразложимые над $$\mathbb{R}$$).
3. **Представление дроби** в виде суммы простейших дробей с неопределенными коэффициентами:
   - Для корня $$(x-a)$$: $$\frac{A}{x-a}$$.
   - Для кратного корня $$(x-a)^k$$: $$\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \dots + \frac{A_k}{(x-a)^k}$$.
   - Для квадратного трехчлена $$(x^2 + px + q)$$: $$\frac{Mx + N}{x^2 + px + q}$$.
4. **Нахождение коэффициентов:** Приводим к общему знаменателю и приравниваем числители. Используем метод частных значений (подставляем корни знаменателя) и метод сравнения коэффициентов при одинаковых степенях $$x$$.
5. Интегрируем полученные простейшие дроби.

## 5. Интегрирование тригонометрических функций.

Методы зависят от вида подынтегральной функции $$R(\sin x, \cos x)$$.

1. **Универсальная подстановка:** $$t = \tg \frac{x}{2}$$. Тогда:

$$\sin x = \frac{2t}{1+t^2}, \qquad \cos x = \frac{1-t^2}{1+t^2}, \qquad dx = \frac{2 \, dt}{1+t^2}$$

Сводит к рациональной дроби.

2. **Нечетность относительно $$\sin x$$** ($$R(-\sin x, \cos x) = -R$$): замена $$t = \cos x$$.
3. **Нечетность относительно $$\cos x$$** ($$R(\sin x, -\cos x) = -R$$): замена $$t = \sin x$$.
4. **Четность относительно обоих** ($$R(-\sin x, -\cos x) = R$$): замена $$t = \tg x$$. При этом:

$$\sin^2 x = \frac{t^2}{1+t^2}, \qquad \cos^2 x = \frac{1}{1+t^2}, \qquad dx = \frac{dt}{1+t^2}$$

5. **Для произведений** синусов и косинусов используем формулы понижения степени или преобразования суммы в произведение.

## 6. Интегрирование иррациональных функций.

Иррациональные функции содержат корни. Основная цель — избавиться от корней.

1. **Дробно-линейная иррациональность:**

$$\int R\left(x, \sqrt[n]{\frac{ax+b}{cx+d}}\right) dx$$

Замена: $$t = \sqrt[n]{\frac{ax+b}{cx+d}}$$.

2. **Квадратичная иррациональность:** интегралы вида $$\int R(x, \sqrt{ax^2 + bx + c}) dx$$. Сводим трехчлен к полному квадрату и используем **тригонометрические подстановки**:
   - Для $$\sqrt{a^2 - x^2}$$: $$x = a \sin t$$.
   - Для $$\sqrt{a^2 + x^2}$$: $$x = a \,\tg t$$.
   - Для $$\sqrt{x^2 - a^2}$$: $$x = \frac{a}{\cos t}$$.

## 7. Определенный интеграл. Определение. Геометрический и физический смысл.

**Определение (по Риману):**

Пусть функция $$y = f(x)$$ определена на отрезке $$[a, b]$$. Разобьем отрезок на $$n$$ частей, выберем на каждом участке точку $$\xi_i$$. Составим интегральную сумму:

$$\sigma = \sum_{i=1}^n f(\xi_i) \Delta x_i$$

Если существует конечный предел этой суммы при $$\max \Delta x_i \to 0$$, не зависящий от способа разбиения и выбора точек $$\xi_i$$, то этот предел называется **определенным интегралом**:

$$\int_{a}^{b} f(x) dx = \lim_{\max \Delta x_i \to 0} \sum_{i=1}^n f(\xi_i) \Delta x_i$$

**Геометрический смысл:** Для $$f(x) \ge 0$$ на $$[a, b]$$ интеграл численно равен площади криволинейной трапеции, ограниченной осью $$Ox$$, прямыми $$x=a$$, $$x=b$$ и графиком функции.

**Физический смысл:** Если $$v(t)$$ — скорость движения, то интеграл $$\int_{t_1}^{t_2} v(t) dt$$ равен пройденному пути. В общем смысле — это накопленная величина (работа, масса, заряд).

## 8. Формула Ньютона-Лейбница. Свойства определенного интеграла.

**Формула Ньютона-Лейбница (основная теорема анализа):**

Если $$F(x)$$ — любая первообразная для непрерывной на $$[a, b]$$ функции $$f(x)$$, то:

$$\int_{a}^{b} f(x) dx = F(b) - F(a)$$

**Свойства:**

1. **Аддитивность:** $$\int_{a}^{b} f dx = \int_{a}^{c} f dx + \int_{c}^{b} f dx$$.
2. **Линейность:** $$\int_{a}^{b} (k_1 f + k_2 g) dx = k_1 \int_{a}^{b} f dx + k_2 \int_{a}^{b} g dx$$.
3. **Изменение направления обхода:** $$\int_{a}^{b} f dx = -\int_{b}^{a} f dx$$.
4. **Интеграл от нуля:** $$\int_{a}^{a} f dx = 0$$.
5. **Теорема о среднем:** Существует точка $$c \in [a, b]$$ такая, что $$\int_{a}^{b} f(x) dx = f(c) \cdot (b - a)$$.

## 9. Вычисление определенного интеграла. Интегрирование по частям. Замена переменной.

**1) Интегрирование по частям:**

$$\int_{a}^{b} u \, dv = \left. u \cdot v \right|_{a}^{b} - \int_{a}^{b} v \, du$$

Здесь подстановка $$\left. u \cdot v \right|_{a}^{b}$$ вычисляется сразу на концах отрезка.

**2) Замена переменной (подстановка):**

Если $$x = \varphi(t)$$ непрерывно дифференцируема на $$[\alpha, \beta]$$, причем $$\varphi(\alpha) = a$$, $$\varphi(\beta) = b$$, то:

$$\int_{a}^{b} f(x) dx = \int_{\alpha}^{\beta} f(\varphi(t)) \cdot \varphi'(t) dt$$

**Ключевое отличие:** **Не нужно возвращаться к старой переменной!** Пересчитываются пределы интегрирования.

## 10. Несобственные интегралы I и II рода.

Интегралы называются несобственными, если нарушено условие существования (промежуток бесконечен или функция имеет разрыв).

**А) Несобственные интегралы I рода (по бесконечному промежутку):**

$$\int_{a}^{+\infty} f(x) dx = \lim_{b \to +\infty} \int_{a}^{b} f(x) dx$$

Аналогично для $$-\infty$$.

Если предел конечен — интеграл **сходится**; если бесконечен или не существует — **расходится**.

**Б) Несобственные интегралы II рода (от разрывных функций):**

Пусть $$x = b$$ — точка разрыва (обращает функцию в бесконечность). Тогда:

$$\int_{a}^{b} f(x) dx = \lim_{\varepsilon \to 0^+} \int_{a}^{b-\varepsilon} f(x) dx$$

Если разрыв во внутренней точке $$c$$, интеграл разбивается на сумму двух интегралов $$\int_a^c + \int_c^b$$, и каждый исследуется на сходимость отдельно.

## 11. Геометрические и физические приложения определенного интеграла.

**Геометрические приложения:**

1. **Площадь плоской фигуры:**
   - В декартовых координатах: $$S = \int_{a}^{b} |f(x) - g(x)| dx$$.
   - В полярных координатах: $$S = \frac{1}{2} \int_{\alpha}^{\beta} r^2(\varphi) d\varphi$$.
2. **Длина дуги кривой:** $$L = \int_{a}^{b} \sqrt{1 + (y')^2} dx$$ (для явной функции) или $$L = \int_{\alpha}^{\beta} \sqrt{(x')^2 + (y')^2} dt$$ (для параметрической).
3. **Объем тела вращения** (вокруг оси $$Ox$$): $$V = \pi \int_{a}^{b} f^2(x) dx$$.
4. **Площадь поверхности вращения:** $$S = 2\pi \int_{a}^{b} f(x) \sqrt{1 + (f'(x))^2} dx$$.

**Физические приложения:**

1. **Работа переменной силы:** $$A = \int_{x_1}^{x_2} F(x) dx$$.
2. **Путь при переменной скорости:** $$S = \int_{t_1}^{t_2} v(t) dt$$.
3. **Статические моменты и центр масс:** $$M_x = \int y \, dm$$, $$M_y = \int x \, dm$$.
4. **Давление жидкости на стенку (по закону Паскаля):** $$P = \rho g \int_{a}^{b} (\text{глубина}) \cdot (\text{длина стенки}) dx$$.
